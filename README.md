# mattbeck1.github.io

Personal website of Matthew Beck, built with [al-folio](https://github.com/alshedivat/al-folio) (Jekyll) and deployed to GitHub Pages by `.github/workflows/deploy.yml`.

- `_pages/` – about, CV, publications, teaching
- `_teaching/` – course entries
- `_bibliography/papers.bib` – publications
- `_data/` – CV, socials

Local preview: `bundle install && bundle exec jekyll serve`
